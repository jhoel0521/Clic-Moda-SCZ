## Glossary (one term per concept)
| UI term | Meaning | Do not use |
|---|---|---|
| Modelo | Un zapato con todos sus colores y tallas (cada talla y color puede tener su precio) | Artículo, Ítem, Producto base |
| Talla | Número de calzado que elige quien compra | Medida, Número |
| Color | Color de una variante del modelo, siempre con su nombre en texto | Tono, solo una muestra de color |
| Agotada | La talla no tiene unidades disponibles (con texto, nunca solo color o tachado) | Sin stock, No hay |
| Últimas unidades | Quedan pocas (de 1 a 3); no se muestra la cantidad exacta | Poco stock, Casi agotado |
| Consultar por WhatsApp | Abrir el chat con el modelo, la talla y el color elegidos; la compra se cierra ahí | Comprar, Pagar, Añadir al carrito (aún no hay carrito) |
| Preguntar cuándo vuelve | Consulta por un modelo con todas las tallas agotadas | Avisarme, Reservar |
| Catálogo | Lista de modelos a la venta en la tienda | Tienda online, Productos |
| Inventario | Pantalla del panel con la matriz de color y talla y las existencias | Stock, Almacén (como pantalla) |
| Imágenes | Fotos subidas en el panel; de ahí salen todos los formatos para compartir | Galería, Archivos |
| Principal | La primera foto de un modelo; es la que ve el catálogo | Portada, Destacada |
| Recojo | Retirar el pedido en el almacén | Retiro, Pick-up |
